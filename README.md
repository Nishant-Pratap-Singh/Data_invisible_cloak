<h1>Invisible Cloak Dataset</h1>

<h2>📌 Overview</h2>

This repository contains a custom dataset titled "Data Invisible Cloak", designed for experiments in Optical Camouflage Using Gaussian Curves.


The dataset consists of reference frames (background-only images) and cloak frames (images where the invisible cloak effect is applied).


<h2>📂 Dataset Structure</h2>

The dataset includes the following 7 image files:

<h3>🔹 Reference Frames (Background Images)</h3>

    - Reference_Frame_1.png

    - Reference_Frame_2.png

    - Reference_Frame_3.png

These images contain only the static background and are used as baseline references.

<h3>🔹 Cloak Frames (Invisible Cloak Effect)</h3>

     - Cloak_Frame_1.png

     - Cloak_Frame_2(1).png

     - Cloak_Frame_2(2).png

     - Cloak_Frame_3.png

These images contain the invisible cloak effect.

<h2>🔗 Frame Mapping</h2>


Each cloak frame corresponds to a specific reference frame:


| Reference Frame | Cloak Frame(s) |  
|----------|----------|
| Reference_Frame_1.png | Cloak_Frame_1.png |
| Reference_Frame_2.png | Cloak_Frame_2(1).png, Cloak_Frame_2(2).png |
| Reference_Frame_3.png | Cloak_Frame_3.png |
